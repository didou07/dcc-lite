DCC Lite - Windows (amd64 = 64-bit, 386 = 32-bit)

Run:
  Unzip the package and double-click DCCLite.exe.
  (SmartScreen warning: More info > Run anyway.)

Needed:
  - Windows 10/11: nothing (WebView2 is built in).
  - Windows 7/8: put a "WebView2" folder (Fixed Version 109) next to DCCLite.exe.
    Without it the interface opens in your browser at http://127.0.0.1:8787.
  - Live TV in the window: install VLC 3.0.x from videolan.org
    (64-bit VLC for amd64, 32-bit VLC for 386).
