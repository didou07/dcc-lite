Previous commands

Click a command to type it into the terminal. Enter types the first match, Shift+Enter runs it. A command starting with a space, or typed while nothing is echoed (passwords), is never saved.

Paste into the terminal

This browser does not let the page read the clipboard (it needs HTTPS). Press Ctrl+V in the box below, then Send. You can also press Ctrl+V or Ctrl+Shift+V directly in the terminal.

Remote access

Open DCC Lite from another computer or phone over HTTPS, protected by a password. Anyone who knows the password can use your devices and their saved passwords: choose a strong one and prefer a LAN or VPN over the open internet.

Not encrypted. With HTTP, the password, the saved device passwords and everything you do in the terminal and file manager can be read by anyone on the path between you and this computer (café Wi-Fi, your provider, a compromised router). Use it only if you accept that, with a long random password.

Used for the links shown below and, with HTTPS, added to the certificate. The remote device opens http(s)://name-or-IP:port. You must also forward this port in your router (and allow it in the firewall) to this computer; DCC Lite cannot do that for you.

          Backup the channel list

          Saves lamedb and the bouquets of the receiver (folder /etc/enigma2) as a .zip file on this computer.

          Restore the channel list

          Puts the channel list files of a backup back on the receiver and reloads them. Other files in the backup (such as settings) are ignored. Download a backup of the current list first if you may want it back.

          Install a plugin (.ipk)

          Uploads the package to /tmp on the receiver and installs it with opkg in a Terminal tab, so you see the whole result.
