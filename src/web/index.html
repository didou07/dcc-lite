      Previous commands

      Click a command to type it into the terminal. Enter types the first match, Shift+Enter runs it. A command starting with a space, or typed while nothing is echoed (passwords), is never saved.

      Paste into the terminal

      This browser does not let the page read the clipboard (it needs HTTPS). Press Ctrl+V in the box below, then Send. You can also press Ctrl+V or Ctrl+Shift+V directly in the terminal.

      Remote access

      Open DCC Lite from another computer or phone with a password. Anyone with it can use your devices, so choose a strong one.

      Not encrypted. Use a long random password.
